プライバシーポリシー

本サービス（以下「当サービス」）は、自己理解診断・自己実現診断を通じて ユーザーの「やりたいこと」や「価値観」を整理・応援することを目的としています。

1. 収集する情報

当サービスは、診断時に入力いただく回答内容を収集します。 また、診断結果を送信するために、LINEログインを利用して ユーザーの LINE userId を取得します。

2. 利用目的

収集した情報は、診断結果の生成・送信およびサービス改善のためにのみ利用します。 LINE userId は、診断結果をプッシュ通知で送るためのみに使用します。

3. 第三者提供

ユーザーの個人情報を、法令に基づく場合を除き、第三者に提供することはありません。

4. 情報の管理

収集した情報は適切に管理し、不正アクセス・漏えい等が起きないよう努めます。

5. 外部サービス利用

当サービスは、OpenAI（ChatGPT API）、LINE Messaging API を利用します。 各サービスの利用規約に基づき、情報が処理されます。

6. 改定について

本プライバシーポリシーは必要に応じて改定することがあります。 最新の内容は常に本ページに掲載します。

7. お問い合わせ

本ポリシーに関するご質問は、運営者までお問い合わせください。 （例：info@example.com）
